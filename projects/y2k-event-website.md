# Y2K Interactive Event Website, Invitations and Posters

A birthday-party package for an event at Rebound Trampoline Park.

## What I made

- Eye-catching invitations and posters in a black, Y2K-inspired look, modelled on reference sample invitations
- An interactive website with a quiz that moves page by page, one question per page
- RSVP replies routed to WhatsApp
